**1. <nav> tag (navigation):**



&#x20;   It is a semantic HTML element used to define a section of a webpage that contains navigation links. It improve accessibility (screen readers can identify navigation sections easily).



Where to use:

&#x20;  1. Top menu

&#x20;  2. Sidebar navigation

&#x20;  3. Footer navigation 



Example:

<nav>

&#x20; <a href="home.html">Home</a>

&#x20; <a href="about.html">About</a>

&#x20; <a href="contact.html">Contact</a>

</nav>





**2. <main> tag**



&#x20;    It represents the main content of a webpage excluding navigation, ads and etc.



Where to use:

&#x20;  1. Use inside the <body> tag

&#x20;  2. Only one <main> tag per page

&#x20;  3. Place it between <header> and <footer>



Example (Structure):

<body>

&#x20; <header>Header content</header>

&#x20; <main>Main content</main>

&#x20; <footer>Footer content</footer>

</body>





**3. <section> tag**



&#x20;     It is used to define a separate section or block of related content in a webpage. It groups content that belongs together under a common topic.



Where to use:

&#x20;  1. Inside <main> for dividing main content

&#x20;  2. Inside articles or pages with multiple topics

&#x20;  3. When content has a clear heading and theme



Common Use Cases:



About section

Services section

Contact section



Example:

<main>

&#x20; <section>

&#x20;   <h2>Services</h2>

&#x20;   <p>We offer web development.</p>

&#x20; </section>



&#x20; <section>

&#x20;   <h2>Contact</h2>

&#x20;   <p>Email us at example@gmail.com</p>

&#x20; </section>

</main>





**4. <article> tag**



&#x20;     It is used to represent independent, self-contained content that can stand on its own. It is used for content that can be read or reused separately from the rest of the webpage.





Where to use:

&#x20;     1. Blog posts

&#x20;     2. News articles

&#x20;     3. Forum posts

&#x20;     4. Product cards



Example:

<main>

&#x20; <article>

&#x20;   <h2>News 1</h2>

&#x20;   <p>Details about news 1.</p>

&#x20; </article>



&#x20; <article>

&#x20;   <h2>News 2</h2>

&#x20;   <p>Details about news 2.</p>

&#x20; </article>

</main>





**5. <aside> tag**



&#x20;    The <aside> tag is a semantic HTML element used to represent content that is indirectly related to the main content. It contains extra or supporting information that is not the main focus.





Where to use:

&#x20;     1. Sidebar content

&#x20;     2. Related links

&#x20;     3. Advertisements

&#x20;     4. Author bio

&#x20;     5. Tips or notes



Example:

<main>

&#x20; <article>

&#x20;   <h2>Learning HTML</h2>

&#x20;   <p>This is the main content.</p>

&#x20; </article>



&#x20; <aside>

&#x20;   <h3>Tip</h3>

&#x20;   <p>Practice daily to improve your skills.</p>

&#x20; </aside>

</main>





**6. <header> tag**



&#x20;      It is used to define the introductory content of a webpage or a section.



Example:

<header>

&#x20; <h1>My Website</h1>

&#x20; <p>Welcome to my website</p>

</header>





**7. <footer> tag**

&#x20;

&#x20;     It is used to define the footer (bottom section) of a webpage or a section. It contains ending or closing information of a page or content.



Example:

<footer>

&#x20; <p>© 2026 My Website</p>

</footer>





**8. <figure> tag**



&#x20;     It is used to represent self-contained content, usually with a caption. It is used to display images, diagrams, charts, or code snippets along with a description.



Example:

<figure>

&#x20; <img src="image.jpg" alt="Nature">

&#x20; <figcaption>Beautiful nature view</figcaption>

</figure>





**9. <time> tag**



&#x20;     It is used to represent date and time values in a machine-readable format.



Example:

<time>May 4, 2026</time>





**10. <mark> tag**



&#x20;     The <mark> tag is a semantic HTML element used to highlight or mark important text.



Example:

<p>This is a <mark>important</mark> word.</p>
